# 检查清单、禁用词与改写示例

成稿后用本文件逐项核对。任何一项不通过都应回到对应步骤修改。

## 一、投稿前检查清单

### 核心故事与结构
- [ ] 能用一句话说清核心故事，非本专业读者可复述。
- [ ] 标题是陈述句、给出结论，符合目标期刊字数/字符限制，无问号、双关、泛泛开头、陌生缩写。
- [ ] 摘要为单段非结构化（或按目标期刊要求带引用），≤150–200 词，四步齐全：背景 / 缺口 / Here we show / 意义。
- [ ] 引言简短、漏斗式，末段概括主要结果与结论。
- [ ] 结果按叙事顺序组织，未在正文大段复述图表。
- [ ] 讨论不重复结果，末段点明主结论与未来方向。
- [ ] 方法置于文末，细节足够复现。

### 语言
- [ ] 每个句子只表达一个意思，主句承载核心信息，短句为主（10–20 词）。
- [ ] 主动语态为主，动词有力，无"僵尸名词"。
- [ ] 无任何 hype 词（见下表）。
- [ ] 术语首次出现有定义，缩写不超过必要范围。
- [ ] 主张强度与证据强度匹配（相关不写成因果）。
- [ ] 无空洞概括，尽量给出具体数字与细节。
- [ ] 时态正确：过去时报告实验、现在时陈述结论。

### 图表
- [ ] 每张图/表读者不看正文即可理解。
- [ ] 图注简短，面板用 a/b/c 标注并逐一解释。
- [ ] 展示单个数据点；误差棒、统计方法、N 在图注中定义。
- [ ] 统计仅针对独立重复实验，坐标轴从 0 起（对数轴除外）。
- [ ] 配色色盲友好且黑白可辨；无无谓的 3D 柱状图。
- [ ] 图表按引用顺序编号，表格可编辑且不与正文重复。

### 诚信与声明（硬性）
- [ ] 正文每个事实性主张都能追溯到用户提供的资料或已核实文献。
- [ ] 无编造的数据、结果、统计值、p 值、样本量。
- [ ] 无虚构参考文献；所有不确定引用以 `[待补引用：……]` 标注。
- [ ] 所有缺失信息以 `[待补：……]` 标注，并已在交付时汇总给用户。
- [ ] 作者贡献、利益冲突、数据/代码可得性声明齐全（按目标期刊）。
- [ ] 涉人类/动物实验的伦理批准、知情同意、注册信息齐全。
- [ ] 如使用 LLM 辅助写作，已在 Methods 中如实说明。

## 二、禁用词与替换对照

| 避免 | 改为 | 理由 |
|---|---|---|
| novel / unprecedented / groundbreaking / remarkable / for the first time | 删除，让结果自己说话 | 夸大引发争议，可信度下降 |
| interestingly / surprisingly | 删除或客观陈述 | 主观词增加歧义 |
| It was found that… / It has been shown that… | We found… / Previous work showed… | 主动语态更简洁有力 |
| make an examination of | examine | 还原动词 |
| perform an analysis of | analyze | 还原动词 |
| present a comparison of | compare | 还原动词 |
| produce an improvement in | improve | 还原动词 |
| be in agreement | agree | 还原动词 |
| due to the fact that | because | 去冗余 |
| in the event that | if | 去冗余 |
| leverage | use | 用短词 |
| demonstrate（可被 show 替代时） | show | 用短词 |
| a significant increase in conversion rate | increased the conversion rate significantly | 动词承载动作 |
| There is / There are 开头的空洞句 | 直接陈述主语 | 去 expletive |
| It should be noted that… | 直接说明 | 去缓冲语 |
| Study of… / Investigation of… / On the…（标题） | 陈述结论的短句 | 标题须有信息量 |
| caused / drove（仅相关证据时） | associated with / accompanied by | 主张匹配证据 |

## 三、Before / After 改写示例

**标题**
- ✗ *Computers don't think like babies*（吸睛但无信息）
- ✗ *Quantifying research waste in ecology*（只说主题与目标，无发现）
- ✓ *Ecologists waste 75% of their research time*（主题 + 关键结论）
- ✓ *Afternoon rain more likely over drier soils*（7 词，无术语，讲清机制）

**摘要结论句**
- ✗ *In this study, we investigated the role of X and found that it was significantly associated with Y. These results suggest that X may potentially be involved in Y.*（被动、模糊、双重缓冲）
- ✓ *Here we show that X drives Y across diverse conditions, establishing a mechanistic link that explains prior contradictory reports.*（主动、具体、给出意义）

**句子聚焦**
- ✗ *The catalyst produced a significant increase in conversion rate.*
- ✓ *The catalyst increased the conversion rate significantly.*

**复杂句拆分**
- ✗ 把三层意思塞进一个 50 词长句。
- ✓ 拆为 3 个 10–20 词的句子，每句一个意思，用 signposting 连接。

## 四、诚信自查红线

出现以下任一情况，必须停止并回到事实清单核对：

1. 正文出现事实清单中不存在的数据或结论。
2. 引用了未经核实的文献，或文献信息（作者/年份/DOI）无法确认。
3. 用 `[待补]` 标注的缺口被"顺手补齐"成了看似合理的内容。
4. 相关关系被写成因果，或观察被写成机制。
5. 统计显著性、样本量、误差棒等在看图/清单中无据可依。
